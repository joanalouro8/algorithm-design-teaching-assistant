# Algorithm Design – Teaching Assistant

This repository contains the reference implementations, evaluation datasets, and automated correction tools developed as part of my work as a **Teaching Assistant for the Algorithm Design (DA) course** at the Faculty of Engineering, University of Porto (FEUP).

The work involved:
- Reviewing and validating programming-based group projects.
- Developing model solutions and evaluation datasets for project assessment.
- Implementing automated correction tools to support project evaluation.

## Projects

### Project 1 – Scientific Conference Review Assignment

**Folder:** [`p1/`](p1/)

Implementation of a scientific conference review assignment tool using a **maximum flow algorithm (Ford–Fulkerson)**.

The program assigns reviewers to conference submissions while respecting constraints such as reviewer expertise, review requirements, and reviewer availability.

**Datasets:** [`dataset_p1/`](dataset_p1/)

---

### Project 2 – Register Allocation and Correction

**Folder:** [`p2/`](p2/)

Implementation of a register allocation tool based on **web construction and interference graph coloring**, accompanied by an automated correction tool.

**Key components:**
- Web construction and interference graph generation.
- Greedy graph coloring for register allocation.
- Spill handling strategies.
- Automated validation of web construction and register assignments.
- Batch execution and correction scripts.

**Datasets:** [`dataset_p2/`](dataset_p2/)
